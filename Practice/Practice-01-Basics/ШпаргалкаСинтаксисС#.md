## **🧰 ФУНКЦИИ В C#**

### **📌 Базовый синтаксис функций**
| Код | Описание |
|-----|----------|
| `void ИмяМетода() { }` | Метод без параметров и возврата |
| `int GetSum(int a, int b) { return a + b; }` | С параметрами и возвратом |
| `static void Main()` | Статический метод |

### **📌 Типы методов**
```csharp
// 1. Без параметров и возврата
void SayHello() 
{
    Console.WriteLine("Привет!");
}

// 2. С параметрами
void PrintMessage(string text)
{
    Console.WriteLine(text);
}

// 3. С возвращаемым значением
int Add(int a, int b)
{
    return a + b;
}
```
### **📌 Параметры методов**
```csharp
// Обычные параметры
void ShowInfo(string name, int age) { }

// Необязательные параметры (со значением по умолчанию)
void Log(string message, bool isError = false) { }

// Переменное количество параметров (params)
int Sum(params int[] numbers)
{
    return numbers.Sum();
}
Sum(1, 2, 3, 4, 5);

// Передача по ссылке (ref, out)
void Reset(ref int value) { value = 0; }
void TryParse(string str, out int result) { }
```
### **📌 Рекурсивные функции**
```csharp
int Factorial(int n)
{
    if (n <= 1) return 1;
    return n * Factorial(n - 1);
}

// Factorial(5) = 5 * 4 * 3 * 2 * 1 = 120
```

### **Пример 3: Генератор случайных чисел**
```csharp
int[] GenerateRandomNumbers(int count, int min, int max)
{
    Random rnd = new Random();
    int[] numbers = new int[count];
    
    for (int i = 0; i < count; i++)
    {
        numbers[i] = rnd.Next(min, max + 1);
    }
    
    return numbers;
}

int[] randomNumbers = GenerateRandomNumbers(10, 1, 100);
```

### **Пример 4: Поиск в массиве**
```csharp
int FindIndex(int[] array, int value)
{
    for (int i = 0; i < array.Length; i++)
    {
        if (array[i] == value)
            return i;
    }
    return -1; // не найден
}
```

### **Пример 5: Фильтрация списка**
```csharp
List<int> FilterEvenNumbers(List<int> numbers)
{
    List<int> result = new List<int>();
    foreach (int num in numbers)
    {
        if (num % 2 == 0)
            result.Add(num);
    }
    return result;
}
```

Console.Write("Введите имя: ");

### **Калькулятор через функцию**
```csharp
double Calculate(double a, double b, char operation)
{
    return operation switch
    {
        '+' => a + b,
        '-' => a - b,
        '*' => a * b,
        '/' => b != 0 ? a / b : double.NaN,
        _ => double.NaN
    };
}

double result = Calculate(10, 5, '+'); // 15
```

### **Проверка четности**
```csharp
bool IsEven(int number) => number % 2 == 0;

int num = 7;
Console.WriteLine(IsEven(num) ? "Четное" : "Нечетное");
```

### **Сумма массива**
```csharp
int SumArray(int[] numbers)
{
    int total = 0;
    foreach (int n in numbers)
        total += n;
    return total;
}

int[] nums = {1, 2, 3, 4, 5};
Console.WriteLine($"Сумма: {SumArray(nums)}"); // 15
```

## **🎯 ВАЖНО ЗАПОМНИТЬ**
1. Все команды заканчиваются `;`
2. Используйте `{ }` для блоков кода  
3. Массивы: фиксированный размер, Списки: динамический
4. `=` для присваивания, `==` для сравнения
5. Функции: `void` если нет возврата, `return` если есть
6. Параметры в скобках `()`, возврат через `->` или `return`
