# 🚀 Шпаргалка: Горячие клавиши VS для C# #

## ▶️ **Запуск и отладка**
| Клавиша | Действие | Клавиша | Действие |
|---------|----------|---------|----------|
| **F5** | Запустить отладку | **Ctrl+F5** | Без отладки |
| **F9** | Точка останова | **F10** | Шаг с обходом |
| **F11** | Шаг с заходом | **Shift+F11** | Шаг с выходом |

## 🧭 **Навигация**
| Клавиша | Действие | Клавиша | Действие |
|---------|----------|---------|----------|
| **F12** | К определению | **Ctrl+-** | Назад |
| **Ctrl+Shift+-** | Вперёд | **Ctrl+,** | Поиск файлов |
| **Ctrl+T** | Перейти ко всему | **Ctrl+F12** | К реализации |
| **Alt+F12** | Быстрый просмотр | | |

## 🔧 **Рефакторинг**
| Клавиша | Действие | Клавиша | Действие |
|---------|----------|---------|----------|
| **Ctrl+R, R** | Переименовать | **Ctrl+.** | Быстрые действия |
| **Ctrl+R, M** | Извлечь метод | **Ctrl+R, V** | Извлечь переменную |
| **Ctrl+R, F** | Инкапсулировать поле | | |

## ✏️ **Редактирование**
| Клавиша | Действие | Клавиша | Действие |
|---------|----------|---------|----------|
| **Ctrl+K, C** | Закомментировать | **Ctrl+K, U** | Раскомментировать |
| **Ctrl+K, D** | Форматировать | **Ctrl+D** | Дублировать строку |
| **Ctrl+L** | Удалить строку | **Tab** | Отступ |
| **Shift+Tab** | Убрать отступ | **Ctrl+Shift+V** | Циклическая вставка |

## 🔍 **Поиск**
| Клавиша | Действие | Клавиша | Действие |
|---------|----------|---------|----------|
| **Ctrl+F** | Поиск в файле | **Ctrl+H** | Замена в файле |
| **Ctrl+Shift+F** | Поиск в решении | **Ctrl+Shift+H** | Замена в решении |

## 💡 **IntelliSense**
| Клавиша | Действие | Клавиша | Действие |
|---------|----------|---------|----------|
| **Ctrl+Space** | Автодополнение | **Ctrl+J** | Показать подсказки |
| **Alt+Enter** | Быстрые исправления | **Ctrl+Shift+Пробел** | Параметры метода |

## 📂 **Окна**
| Клавиша | Действие | Клавиша | Действие |
|---------|----------|---------|----------|
| **Ctrl+Alt+L** | Solution Explorer | **F4** | Properties |
| **Ctrl+Alt+O** | Output | **Ctrl+\, E** | Error List |
| **Ctrl+Alt+P** | Attach to Process | | |

## 🏗️ **Сборка и код**
| Клавиша | Действие | Клавиша | Действие |

| **Ctrl+Shift+B** | Собрать решение | **Ctrl+M, M** | Свернуть регион |

| **Ctrl+Shift+Alt+↑/↓** | Мультикурсор | **Ctrl+K, S** | Вставить сниппет |
