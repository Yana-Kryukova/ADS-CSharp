**Цель:** Изучить синтаксис и применение методов в C#: возврат значений, передача параметров по ссылке (ref/out), возврат нескольких значений, работа с массивами.

**Задачи для реализации (все методы `static`):**

1.  **Метод SumOfDigits:**
    *   Принимает: целое число (`int`).
    *   Возвращает: сумму его цифр (`int`).
    *   Пример: для входа 123 → возврат 6.

2.  **Метод Swap:**
    *   Принимает: два целых числа по ссылке (`ref int a, ref int b`).
    *   Возвращает: `void`.
    *   Действие: меняет значения переменных местами.

3.  **Метод FillRandom:**
    *   Принимает: массив целых чисел (`int[] array`).
    *   Возвращает: `void`.
    *   Действие: заполняет массив случайными числами.

4.  **Метод FindFirstPositive (два варианта):**
    *   **Вариант А (out):** Принимает массив `int[]` и `out int result`. Возвращает `bool`. Если найден положительный элемент — записывает его в `out` и возвращает `true`, иначе возвращает `false`.
    *   **Вариант Б (nullable):** Принимает массив `int[]`. Возвращает `int?`. Возвращает `null` если положительное число не найдено, иначе возвращает само число.

**Тестирование:**
В методе `Main` протестировать все методы (вызвать каждый минимум один раз, продемонстрировав корректность работы).

**Дополнительно: Nullable**
*   Кратко: Тип данных, позволяющий значимым типам (value types) принимать значение `null`. Объявляется через `?` (например, `int?`). Используется для обозначения "отсутствия значения".
