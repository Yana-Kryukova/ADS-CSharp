# Алгоритмы и структуры данных на C#

Репозиторий учебных материалов курса **«Алгоритмы и структуры данных»** для направления **«Информационные системы и технологии»**.

## 📚 О курсе

Курс знакомит студентов с фундаментальными алгоритмами, структурами данных и принципами их анализа, используя язык программирования **C#**. Основной фокус — на понимании вычислительной сложности, практическом применении структур данных и решении типовых алгоритмических задач.

## 🎯 Цели курса

- Освоить базовый и продвинутый синтаксис C#, необходимый для реализации алгоритмов
- Понимать и применять асимптотический анализ (О-нотацию) для оценки эффективности алгоритмов
- Изучить основные структуры данных и их реализации в .NET
- Научиться применять алгоритмические паттерны ("два указателя", "скользящее окно" и др.)
- Развить навыки решения алгоритмических задач

## 📖 Структура курса

Курс состоит из **8 лекций** и **16 практических занятий**:

### Лекции
1. **Введение в C#. Базовый синтаксис, типы данных, управляющие конструкции**
2. **C#: Методы, массивы, основы ООП. Значимые и ссылочные типы. String и StringBuilder**
3. **Анализ сложности алгоритмов. Простые структуры данных: списки (List<T>)**
4. **Алгоритмы сортировки и поиска** (Quicksort, Mergesort, бинарный поиск)
5. **Стеки, очереди, хеш-таблицы** (Stack<T>, Queue<T>, Dictionary, HashSet)
6. **Деревья. Бинарные деревья поиска (BST)**
7. **Графы: представление, обход, алгоритмы** (DFS, BFS)
8. **Жадные алгоритмы и динамическое программирование (введение)**

### Ключевые практические темы
- Алгоритмические паттерны: "два указателя", "скользящее окно"
- Реализация алгоритмов сортировки и поиска
- Работа с коллекциями .NET: List<T>, Stack<T>, Queue<T>
- Применение словарей и множеств (Dictionary, HashSet)
- Реализация деревьев и графов

Курс включает **4 контрольные работы**, каждая состоит из **2 задач по вариантам**:

1. **Контрольная 1:** Синтаксис C# (лекции 1-2) ДАТА ПРОВЕДЕНИЯ 12.03.2026 г.

## 🚀 Как начать работу

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Yana-Kryukova/ADS-CSharp.git
   ```

2. **Установите .NET SDK** (версия 8.0 или выше):
   - [Скачать с официального сайта](https://dotnet.microsoft.com/download)

3. **Настройте среду разработки:**
   - Рекомендуется Visual Studio 2022+ [Скачать с официального сайти](https://visualstudio.microsoft.com/ru/free-developer-offers/) или Rider
   - Альтернатива: VS Code с расширениями C# и .NET

4. **Изучайте материалы** в порядке, указанном в [плане курса](./COURSE-PLAN.md)

## 📝 Рекомендации по обучению

1. **Регулярная практика:** Выделяйте время на решение задач каждый день
2. **Анализ сложности:** Для каждого алгоритма определяйте временную и пространственную сложность
3. **Сравнение решений:** Пробуйте разные подходы к решению одной задачи
4. **Использование отладчика:** Освойте отладку кода для понимания работы алгоритмов
5. **Участие в обсуждениях:** Задавайте вопросы и обсуждайте решения с коллегами
